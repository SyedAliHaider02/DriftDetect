How to generate your reports

1. Download the collector script.

2. Run it in your development environment: 

python driftdetect.py --name development --output development.json

3. Run it separately in your production environment: 

python driftdetect.py --name production --output production.json

4. Upload both JSON reports in the section below.

The collector records environment metadata and whether selected configuration variables exist, not their values. Review each report before uploading it.
